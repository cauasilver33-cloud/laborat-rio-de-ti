# Laboratório de TI

Este repositório reúne registros e práticas realizadas durante meus estudos na área de Tecnologia da Informação.

O objetivo do laboratório é documentar conhecimentos básicos relacionados a sistemas operacionais, redes, hardware e troubleshooting, utilizando ferramentas do Windows e testes práticos.

## Conteúdos estudados

### Windows

Estudo de ferramentas e recursos do sistema operacional Windows, incluindo a instalação do sistema e registros relacionados ao seu funcionamento.

📁 Pasta: `windows`

---

### Redes

Estudo dos conceitos básicos de redes de computadores, incluindo:

- Endereçamento IP;
- Máscara de rede;
- Gateway;
- LAN e WAN;
- Switch;
- Roteador;
- Comunicação entre dispositivos;
- Testes de conectividade utilizando o comando `ping`.

📁 Pasta: `redes`

---

### Hardware

Estudo dos principais componentes físicos de um computador e suas funções.

Principais componentes abordados:

- CPU;
- Memória RAM;
- Armazenamento;
- GPU;
- Placa-mãe;
- Fonte de alimentação.

📁 Pasta: `hardware`

---

### Troubleshooting

Estudo de procedimentos básicos para identificação e investigação de problemas relacionados a computadores, redes e dispositivos.

Foram utilizados recursos como:

- Gerenciador de Tarefas;
- Gerenciador de Dispositivos;
- Comando `ping`;
- Análise básica de CPU, memória e processos.

📁 Pasta: `troubleshooting`

---

## Objetivo

Este laboratório foi criado para registrar minha evolução nos estudos e reunir exemplos práticos dos conhecimentos adquiridos na área de suporte e infraestrutura de TI.

Os conteúdos presentes neste repositório incluem registros, anotações e capturas de tela das ferramentas e testes realizados durante os estudos.
